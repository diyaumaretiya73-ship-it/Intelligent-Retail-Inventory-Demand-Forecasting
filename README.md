# Intelligent Retail Inventory and Demand Forecasting System

## Project Overview

The Intelligent Retail Inventory and Demand Forecasting System is an Artificial Intelligence based retail analytics project designed to improve inventory management.

The system predicts product demand using factors such as sales, stock, price, promotions, holidays, weather, local events, competitor price and supplier lead time.

## Key Features

* Demand forecasting using XGBoost and LSTM
* Ensemble-based demand prediction
* Automatic reorder alerts
* Smart reorder point calculation
* Purchase order quantity recommendation
* Dead stock identification
* 20% discount suggestion for dead stock
* Supplier lead time prediction
* Head-office inventory dashboard
* Store manager inventory alerts

## Project Workflow

Dataset → Data Cleaning → EDA → XGBoost → LSTM → Ensemble → Demand Forecast → Inventory Logic → Reorder → Dead Stock → Lead Time → Dashboard

## Project Files

* `Intelligent_Retail_Inventory_Project.ipynb` – Main project notebook
* `dataset.csv` – Retail dataset used for the project

## Project Outcome

The system provides AI-based demand predictions and inventory alerts to help identify low-stock products, dead stock and suitable reorder quantities.
